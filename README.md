# Pathway — Job Application Tracker

A responsive, browser-only demo of a job search dashboard inspired by the resume project description.

## Demo features

- Track company, role, status, application date and next step.
- Search and filter applications.
- Compare pasted job-description text against a small local keyword list.
- Save demo records in browser local storage.

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Deployment

This static prototype can be hosted with GitHub Pages from the repository's root folder. It does not include the Spring Boot API, MySQL database, JWT authentication, file uploads, or an LLM integration described in the resume. The analyzer is a local keyword snapshot, not AI advice.

All names and applications shown are fictional sample data.
